# PORTEX — Hyperlocal Classifieds & On-Demand Logistics Platform

> **The Power of OLX + Porter in One Seamless Enterprise Platform**

PORTEX is a high-performance, full-stack Next.js marketplace and hyperlocal delivery engine. Users can buy and sell verified pre-owned goods (electronics, furniture, vehicles, fashion) and instantly schedule on-demand pickup and delivery through an integrated multi-tier logistics fleet (2-Wheelers, 3-Wheeler Tempos, Tata Ace, Pickup 8ft, 14ft Canter Trucks).

---

## Key Features

### 🛒 Hyperlocal Marketplace (OLX Experience)
- **Verified Listings**: Multi-category catalogue with condition badges, dynamic filters, image galleries, and pricing analytics.
- **Instant Porter Triggers**: Every listing card and detail page features a one-click *"Deliver It"* trigger with auto-calculated weight and dimensions.
- **Buyer & Seller Negotiation**: Real-time counter-offers, chat interface, and escrow-backed transaction safety.
- **Post an Item Wizard**: Multi-step wizard with category selection, automated package dimension estimation, and pickup location geocoding.

### 🚚 On-Demand Logistics Engine (Porter Experience)
- **Multi-Vehicle Fleet**: Bike Express, 3-Wheeler Tempo, Tata Ace (Chota Hathi), 8ft Pickup, and 14ft Canter with real-time base fare + per-km pricing.
- **Add-on Services**: Driver helper, ground-floor/upper-floor labor assistance, and fragile item transit protection.
- **Dual-OTP Handshake**: Secure cryptographic pickup OTP and drop-off delivery verification.
- **Live Interactive GPS Tracking**: Real-time animated vector map with telemetry (speedometer, ETA, distance, driver contact).
- **GST-Compliant Tax Invoices**: Automated downloadable invoices featuring MANGO TECH ENTERPRISES (GSTIN: `09ABRFM9138P1Z3`).

### 📱 Driver Partner Dashboard
- **Radar Dispatch**: Proximity job radar with accept/reject timers and distance-based fare calculation.
- **Earnings & Telemetry**: Today, weekly, and monthly earnings breakdown with trip history and driver rating.
- **Document KYC & Vehicle Status**: Fast-tracked onboarding and vehicle registration management.

### ⚙️ Enterprise Admin Suite
- **Analytics & GMV Metrics**: Real-time gross merchandise value, delivery volume, active drivers, and dispute resolution.
- **Configurable Business Profile**: Dynamic business registration details, GST rate adjustments, platform fee percentages, and contact hubs.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router & Turbopack)
- **Language**: TypeScript 5
- **UI Library**: React 19
- **Styling**: Tailwind CSS & Modern Glassmorphism
- **Icons**: Lucide React
- **Database Architecture**: Prisma Schema (PostgreSQL ready)
- **State Management**: React Context Store with client-side localStorage synchronization

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed
- npm or pnpm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Satyacoder-31/portex.git

# Navigate into directory
cd portex

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm start
```
